# LeadBrief

Cited contact briefs for sales reps, built with Laravel, pgvector and a local LLM.

> **Status:** work in progress. This README will be completed as the project evolves.

## The problem

Before reaching out to a lead, a sales rep needs context that is scattered across notes,
calls, emails and meetings. LeadBrief generates a short brief for a contact where every
claim cites its source notes, and answers questions about the contact. When there is not
enough context, it says so instead of making things up.

## Stack

- **Backend:** Laravel (PHP 8.3+), Laravel queues
- **Database:** PostgreSQL with pgvector
- **Frontend:** Vue 3, Pinia, Vite
- **AI:** Ollama running locally (CPU inference, zero inference cost)
- **Infra:** Docker Compose

All data in this project is synthetic and generated by a seeder.
No real customer data is used.
